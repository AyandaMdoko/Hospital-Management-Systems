# Hospital Management System — Landing Page

A responsive landing page concept built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — blue-and-white visual design and responsive layouts
- `script.js` — mobile navigation menu and dynamic footer year

## Run locally
1. Place the `hospital_management_landing_page` folder inside your XAMPP `htdocs` directory.
2. Start Apache from the XAMPP Control Panel.
3. Open `http://localhost/hospital_management_landing_page/` in your browser.

The Login and Access System links currently point to `login.php`. That page will need to be created as the next step. The landing page itself does not authenticate users or access patient records.

## Notes
- The hero image is loaded from Unsplash, so an internet connection is needed to display it.
- Google Fonts is used for the DM Sans typeface; a system sans-serif fallback is included.
- This is the public landing page only. It does not yet include login, dashboards, database connectivity or role-based access.
